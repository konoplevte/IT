# Информационные технологии

Материалы курса по разработке приложений: лекции и лабораторные работы. В течение двух семестров мы изучаем совместную разработку, работу с сетью, фреймворки, тестирование и развёртывание на примере создания **ИИ-агента**.

Цель курса — разработать собственного агента, который использует большую языковую модель (LLM) и инструменты для взаимодействия с внешними сервисами. Примеры на лекциях написаны на **Python**; лабораторные работы можно выполнять на другом языке программирования.

## Как работать с курсом

1. Изучите лекцию и выполните приведённые в ней примеры.
2. Откройте соответствующую лабораторную работу: в ней указаны задание, ограничения, критерии оценивания и вопросы для защиты.
3. Выполните задание в своём репозитории на GitLab или GitHub, создав отдельную ветку `task1`, `task2` и так далее.
4. Отправьте изменения и создайте merge request (MR) в GitLab или pull request (PR) в GitHub с целевой веткой `main`.
5. Предоставьте преподавателю доступ, назначьте его reviewer и отправьте отдельное письмо со ссылкой на запрос. Тема письма: `ИТ — ЛР N — ФИО — группа`, где `N` — номер работы.
6. Исправьте замечания в той же ветке. После одобрения преподавателя защитите работу очно.

**Не сливайте MR или PR до одобрения преподавателя. Защита обязательна.** Подробные правила сдачи, сроки и порядок начисления баллов приведены в задании каждой лабораторной работы.

Можно пользоваться любыми инструментами, но необходимо понимать свою работу и уметь объяснять и изменять написанный код.
